# EmailPhishDetectionUsingBERT
The goal of this project was to build a machine learning model capable of identifying phishing emails based on their textual content. With phishing attacks becoming increasingly sophisticated, relying on traditional detection methods like keyword matching or rule-based systems is no longer sufficient. These older approaches often fail to capture context or adapt to the evolving strategies used by attackers, specifically how attackers may leverage generative AI models – like ChatGPT – to create superior phishing emails. 
The dataset used was derived from Enron's email dataset hosted by Carnegie Mellon University which includes 500,000 emails from 150 employees in 2003. The actual dataset used during training is a pre-labeled version of Enron's dataset found on Kaggle, authored by Naser Abdullah Alam and Amith Khandakar (dataset link: https://www.kaggle.com/datasets/naserabdullahalam/phishing-email-dataset?select=Enron.csv). This dataset included 'subject' and 'body' features with a binary-encoded label. This dataset was split into 80:10:10 as training:testing:validation. 

For actual model training, we used Google's bert-base-uncased model on Hugging Face with training arguments:
* Learning rate: 2e-5
* Epochs: 5
* Batch size: 8
* Weight decay: 0.01
* Evaluation and saving strategy: Every epoch
* Best model selection: Based on validation accuracy

Overall, the model identified phishing attempts with high precision while keeping false negatives low, performing exceptionally well towards the Enron dataset by achieving a ~99.5% accuracy. 

The model was tested on an artificial dataset of phishing and legit emails, generated by ChatGPT. This was done to simulate how modern attackers may utilize generative AI to create in-context phishing emails, becoming potentially more dangerous and harder to identify. The following prompt was used after including the initial Enron dataset for generation: “Please create a dataset of 100 email body texts following the format of the attached dataset. 50 must be phishing emails and 50 must be legit emails.”
The model's accuracy and f1-score dropped to ~95% when tested on the new dataset which suggests some difficulties in generalizing to new data, but our fine-tuned LLM model still performs satisfactorily overall.
